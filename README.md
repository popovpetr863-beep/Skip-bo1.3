# TableTop — Skip-Bo

Онлайн-версия Skip-Bo на Node.js + Express + Socket.IO. Система создания комнат взята за основу из проекта «Переворот», игровая логика заменена на Skip-Bo.

## Правила этой версии
- 2–4 игрока.
- Каждый получает стартовую STOCK-стопку из 30 карт.
- Верхняя карта STOCK открыта.
- На ход игрок добирает руку до 5 карт.
- Можно играть верхней картой STOCK, верхней картой одного из 4 личных сбросов или картой из руки.
- Центральные 4 BUILDING-стопки строятся от 1 до 12.
- SKIP-BO — универсальная карта.
- Когда центральная стопка достигает 12, она убирается в общий резерв и позже перемешивается обратно в DRAW, когда колода заканчивается.
- Если все 5 карт руки сыграны, игрок автоматически добирает ещё 5 и продолжает ход.
- Ход заканчивается сбросом одной карты из руки в один из 4 личных сбросов.
- Побеждает тот, кто первым избавился от всей своей STOCK-стопки.
